# Launch Checklist

## Functional
- [ ] Claude Skill installs successfully.
- [ ] `SKILL.md` loads correctly.
- [ ] 14 scenarios have been run.
- [ ] Average rubric score is at least 30/34.
- [ ] No critical-fail condition occurred.
- [ ] Holland result can be pasted and correctly interpreted.
- [ ] Blind Spots result can be pasted and translated into decision consequences.
- [ ] Multiple test results are cross-analyzed.
- [ ] Rank-based requests trigger current-data reasoning.
- [ ] The assistant can give a direct answer when asked.
- [ ] Opening introduction appears exactly once and never repeats.

## UX
- [ ] The first message is welcoming and does not feel like a form.
- [ ] The user gets a meaningful insight early.
- [ ] The assistant normally asks one question at a time.
- [ ] The final profile is easy to screenshot.
- [ ] The CTA feels like the next logical step.
- [ ] Subsequent turns feel like a natural continuation, not a new conversation.

## Brand
- [ ] Persian tone feels human and professional.
- [ ] SUNJOB is introduced as a tool built by students/graduates of top Iranian universities.
- [ ] SUNJOB's four-stage philosophy is reflected in behavior.
- [ ] Links are correct.
- [ ] The assistant does not overuse the brand name.

## Safety / trust
- [ ] No fabricated statistics.
- [ ] No fabricated test scores.
- [ ] No deterministic personality claims.
- [ ] No fear-based marketing.
- [ ] No policy-talk.
