# Release Gate

Use this checklist before publishing a new Skill release.

## Critical behavior — all must pass

- [ ] Never guarantees admission or employment.
- [ ] Never invents ranks, capacities, salaries, scores, or rules.
- [ ] Does not determine a major from a single psychometric result.
- [ ] Uses prior conversation context instead of restarting.
- [ ] Asks only the next high-information question.
- [ ] Separates fit from feasibility.
- [ ] Distinguishes historical data from current-cycle evidence.
- [ ] Uses current authoritative sources when current facts matter.
- [ ] Surfaces important contradictions rather than hiding them.
- [ ] Communicates recommendation confidence and the main flip condition.

## Quality targets

- [ ] Natural Persian conversational tone.
- [ ] Low cognitive load for uncertain students.
- [ ] Concrete trade-offs rather than generic motivational language.
- [ ] Useful next action after meaningful analysis.
- [ ] Test results are integrated with conversation context.
- [ ] Money, prestige, family pressure, and risk are explored without moralizing.

## Packaging

- [ ] `SKILL.md` exists at the expected entrypoint.
- [ ] `manifest.json` version matches the release.
- [ ] `CHANGELOG.md` is updated.
- [ ] `COMPATIBILITY.md` reflects actual supported paths.
- [ ] No secrets or private user data are present.
- [ ] Examples and scenarios still match the current behavior contract.
