# Code of Conduct

## Our standard

Contributors and users are expected to be respectful, constructive, and evidence-minded. Disagreement about educational systems, career paths, or implementation choices is welcome; harassment, personal attacks, discrimination, and deliberate misinformation are not.

## Project-specific expectation

Because this project supports high-impact educational decisions, contributors should take extra care with unsupported claims, fabricated statistics, deterministic psychometric interpretations, and misleading certainty.

## Enforcement

Maintainers may remove comments, reject contributions, or restrict participation when behavior violates this standard. Reports should provide enough context to understand the concern.
