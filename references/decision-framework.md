# Decision Framework

A major decision should be analyzed in four layers:

**SELF × BIAS × CAREER × REALITY → DECISION**

## SELF
interests + personality tendencies + values + abilities + work style + self-efficacy

What the student is genuinely drawn to, capable of, and motivated by.

## BIAS
prestige + rank + family + peers + fear + salary + social proof

External pressures and cognitive shortcuts that distort genuine preference. BIAS is not a valid decision input — it is a noise layer to detect and subtract.

## CAREER
real work + environment + skills + lifestyle + growth + specialization

What the major actually leads to in practice: daily tasks, work settings, career trajectories, and quality of life.

## REALITY
rank + quota + geography + university + finances + current rules

Feasibility constraints. The rank is an important input that determines which doors may be open; it does not determine which door the student should walk through.

## DECISION
prioritized options

The output: a ranked shortlist of 3–5 directions, each with fit reasoning, mismatch risk, and confidence level.

## Rule
Never let one dimension silently replace the others. A decision that only considers REALITY (rank-based) or only considers BIAS (prestige-driven) is incomplete.
