# Test Integration Guide

## Holland
Use exact user-provided scores. Discuss patterns and combinations. Never produce missing scores.

## Work Values
Use to compare environments and break ties between majors that both fit interests.

## Blind Spots
Translate the result into likely decision behavior and practical safeguards.

## Career Self-Efficacy
Interpret confidence in career-management tasks, not raw ability.

## MBTI / Big Five
Supplementary lenses only. Do not use them as deterministic career-selection algorithms.

## Cross-analysis
Best practice:
1. summarize each input;
2. identify where they converge;
3. identify where they disagree;
4. explain what the disagreement means;
5. ask what additional evidence would resolve it.
