# Contributing to SUNJOB Math Major Skill

Thank you for helping improve the Skill.

## What is useful to contribute

- Better evaluation scenarios and edge cases.
- Clearer decision-support workflows.
- Improvements to research and source-handling guidance.
- Documentation and compatibility updates.
- Corrections that improve Persian UX without changing the intended methodology.

## Before changing `SKILL.md`

1. Read the current Skill and the relevant files under `references/`.
2. Preserve the core decision model and evidence standards.
3. Do not introduce deterministic major recommendations from a single test.
4. Do not invent admission statistics, ranks, capacities, salaries, or rules.
5. Add or update an evaluation scenario for meaningful behavior changes.
6. Update `CHANGELOG.md` when the behavior contract changes.

## Pull requests

A good pull request should explain:

- what changed;
- why the change is needed;
- which scenarios or documentation were updated;
- any compatibility implications.

Keep changes focused and avoid unrelated refactors.
