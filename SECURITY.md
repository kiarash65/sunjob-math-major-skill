# Security Policy

## Scope

This repository contains an AI Skill: instructions, examples, references, and a ChatGPT adaptation. It is not an application backend and should not contain secrets or private user data.

## Safe usage

AI Skills can influence model behavior. Before installing a Skill from any third party, review its instructions and any included code or supporting resources. Do not provide sensitive credentials, passwords, private student records, or confidential organizational data to an AI workflow unless the tool and workflow are explicitly designed and authorized to handle them.

The SUNJOB Skill is intended for educational and career decision support. It should not be treated as a substitute for official admission rules, current government/university information, or qualified professional judgment.

## Reporting a security issue

Do not publish sensitive security details in a public issue. Contact the repository maintainer privately through the GitHub account associated with this repository and include:

- affected file/version;
- a concise description of the issue;
- reproduction steps when possible;
- potential impact.

Please do not include passwords, API keys, private student information, or other secrets in a report.
